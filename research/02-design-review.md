# 설계 검토 결과

초기 설계(화면 감시 + Playwright CDP 연결 + 예매자 정보 자동입력)를 검토한 결과입니다. NOL 내부 구조에 대한 내용은 사전 조사로 확인해야 하는 가설입니다.

## 핵심 발견: 좌석맵은 저절로 바뀌지 않을 수 있음

예매 사이트 좌석맵은 보통 불러온 시점의 모습에 머뭅니다. 그렇다면 기존 `nol_screen_alert.py`(화면 픽셀 비교)는 화면이 변하지 않으므로 아무것도 감지하지 못합니다.

→ 사전 조사 첫 질문: **좌석맵을 열어두면 저절로 갱신되는가?** (1시간 관찰, DevTools Network에서 주기적 XHR/WebSocket 확인)
- 갱신된다 → 관찰만으로 충분. 자동 새로고침 불필요
- 갱신 안 된다 → 새로고침이 필요하며, 이것이 약관상 가장 민감한 부분

## 권고와 반영 여부

| # | 권고 | 근거 | 반영 |
|---|---|---|---|

| 2 | Playwright CDP 대신 크롬 MV3 확장 | 크롬 136부터 기본 프로필에서 `--remote-debugging-port` 무시됨. 확장이 탭 제어·알림을 기본 제공. 단, Windows 포그라운드 잠금은 확장도 피하지 못함 → `drawAttention` + 알림 클릭 시 포커스로 보완 (DESIGN 11.1) | 반영: 구조 변경 |
| 3 | 잔여석 수 먼저 감시하는 2단계 구조 | 좌석맵 반복 새로고침보다 가벼움 | 보류: 대상 공연은 `잔여석 숨김`이라 적용 어려움 |
| 4 | 취소표가 풀리는 시간대에 집중 | 같은 요청 수로 더 잘 잡음 | 반영: FR-7 시간대 제한 |

| 7 | 예매자 정보 자동입력 축소, DPAPI/keyring 제거 | NOL이 계정 정보로 미리 채울 가능성 큼 | 반영: FR-15 (빈 칸만, 필요 시) |

| 9 | OS 접근성(UI Automation) 사용 안 함 | 크롬 접근성 트리 불완전, 캔버스는 정보 없음 | 반영: 제외 |
| 10 | 새로고침 간격에 무작위 지연 추가 | "기계처럼 보이지 않게" | **채택 안 함.** 봇 탐지 회피에 해당 |
| 11 | 과설계 피하기: 플러그인 레지스트리 없이 어댑터 2~3개 | 단순성 | 반영 |

## 기타 메모

- 백그라운드 탭 타이머는 크롬이 제한함(숨김 5분 후 약 1분에 1회) → `chrome.alarms` 사용 (MV3 최소 30초)
- 대기열 화면이 나오면 자동 새로고침 중단 후 알림. 대기열 자동 통과 금지
- 별도의 keep-alive 요청은 두지 않음. 새로고침 자체가 세션 유지 역할
- MV3 `webRequest`로는 응답 본문을 읽을 수 없음 → MAIN world 스크립트로 페이지의 fetch/XHR 응답을 **읽기만** 함

## 2단계 코드 검토 (2026-11-16, Antigravity 계획 모드)

검토 대상: manifest, background, store, config-validate, 옵션 페이지, 테스트. 12건 중 9건 반영, 2건 미반영, 1건은 동작 변화 없는 정리.

| # | 지적 | 판단 |
|---|---|---|
| 1 | `chrome.runtime.OnInstalledReason`이 런타임에 없다 | 사실 아님 (크롬 API에 존재). 문자열 `"install"`로 단순화만 함 |
| 2 | `loadUserConfig`가 `{config, warnings}`를 그대로 반환 | 반영: 설정 객체만 반환, 경고는 콘솔 |
| 3 | 상품코드 없이 저장하면 필터 입력이 사라짐 | 반영: 저장 막고 오류 표시 |
| 4 | `clearTab`이 직렬화되지 않아 닫힌 탭 상태가 되살아날 수 있음 | 반영 + 테스트 |
| 5 | 폼 저장 시 `targets[1]` 이후 유실 | 반영: 보존 |
| 6 | `updateTab`이 `this`에 의존, async 콜백 미지원 | 반영 + 테스트 |
| 7 | 열 범위 한쪽만 입력하면 지워짐 | 반영: 저장 막고 오류 표시 |
| 8 | `root.NCA.detector` 직접 참조 | 반영: 없으면 명확한 오류 |
| 9 | `unlimitedStorage` 과다 권한 | 미반영: 이벤트 로그 90일 보관(DESIGN 16, NFR-5)에 필요. 검토 입력에 16절이 빠져 생긴 오해 |
| 10 | 시간대 `~` 구분자 미지원 | 반영 |
| 11 | store 경쟁 상태 테스트 없음 | 반영 |
| 12 | 폼 ↔ 검증 왕복 테스트 없음 | 반영: `options/form-model.js`로 분리, 왕복 테스트 8개 |

참고: 비대화형 실행에서 Antigravity는 셸 명령 권한을 물을 수 없어 자동 거부된다. 파일 내용을 지시문에 넣어 도구 없이 분석시켰다.

## 3단계 코드 검토 (2026-11-16, Antigravity 계획 모드)
